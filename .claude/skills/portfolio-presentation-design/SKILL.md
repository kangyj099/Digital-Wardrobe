# Portfolio Presentation Design

## Core Principle

This is a presentation slide, NOT a web UI.

Prioritize:
1. Visual hierarchy
2. Composition
3. Typography
4. Diagram as visual storytelling
5. Content density

Avoid:
- Card-heavy layouts
- Dashboard aesthetics
- Excessive shadows
- Excessive rounded rectangles
- Small text
- Decorative UI components
- Equal-weight information blocks

## Diagram Rules

When a diagram is the primary content:

- Diagram should occupy 40–60%+ of the slide.
- Do not treat diagrams as small supporting widgets.
- Prefer large geometric forms over thin connector lines.
- Prefer arrows, chevrons, arcs, bands, and spatial relationships.
- Avoid "box → connector → box" unless the relationship itself is the subject.
- Diagram should be readable from presentation distance.
- Supporting text should explain the diagram, not compete with it.

## Anti-AI-Web-UI Rules

Do NOT:
- wrap every concept in a card
- create 3–5 equal information panels
- use subtle shadows everywhere
- use rounded rectangles as generic containers
- distribute content evenly just to make the layout "balanced"
- make diagrams visually polite or small
- optimize for webpage scrolling
