1. 화면 개요
디지털 옷장(Digital Closet)의 옷장 메인 화면. iOS 스타일 풀스크린, 390×844(iPhone 기준) 세이프에어리어 대응. 엣지-투-엣지 그리드로 옷 아이템을 표시.

2. 레이아웃 구조 (z-index 순)
상태바(9:41, 신호/와이파이/배터리) — 표시용, 터치 불가
상단 좌측: "옷장 ▾" 필 버튼(카테고리 드롭다운 트리거) / 선택 모드 시 "N개 선택됨"으로 텍스트 전환
상단 우측: "선택"/"취소" 토글 버튼
카테고리 드롭다운(옷장/코디/스타일 일지 3항목, 활성 항목에 도트 표시)
두 번째 툴바 행(선택 모드 아닐 때만 노출):
좌: "계절 ▾ / {현재계절} ▾" 세그먼트 필(계절 드롭다운 트리거, 계절 옵션: 전체/봄·가을/여름/겨울)
우: 밀도 전환 버튼(▦→▥→▢ 3단계 순환, 그리드 컬럼 5→3→1)
최우측: 원형 버튼(◎, 기능 미정 — 자리표시자)
계절 드롭다운 패널(4항목, 활성 항목 도트)
메인 콘텐츠: 세로 스크롤 그리드
아이템 정사각형 타일, 1px 갭
각 타일: 좌하단 라벨(모노스페이스, 소문자 영문), "미완성" 배지(우상단, 조건부), 선택 모드 시 우상단 체크서클
스크롤 시 상단이 페이드 마스크로 부드럽게 사라짐(그라디언트 마스크, 헤더 아래로 콘텐츠가 스며들듯)
하단 좌: 뒤로가기 원형 버튼(←)
하단 우: "+" FAB, 탭하면 "이 분류에 여러 장/한 장 추가하기" 옵션 2개가 위로 펼쳐짐(펼침 시 + 버튼 45도 회전)
선택 모드 진입 시: 하단에 삭제 바(휴지통 아이콘 + "삭제", 0개 선택시 비활성 스타일)
삭제 실행 시: 하단 중앙 토스트("휴지통으로 이동됨" + "실행취소" 버튼, 3.2초 후 자동 사라짐)
홈 인디케이터 바(화면 최하단)
3. 인터랙션 / 상태
선택 모드: 토글 시 헤더 좌측 텍스트 전환, 두 번째 툴바 행과 원형 버튼 숨김, 하단 삭제 바 노출. 타일 탭 시 다중 선택(체크서클 채움).
삭제: 선택 항목을 "휴지통"으로 이동(즉시 그리드에서 사라짐) → 선택 모드 해제 → 토스트 노출 → "실행취소" 탭 시 원상복구.
밀도 전환: 그리드 컬럼 수 5/3/1 순환 토글.
계절 필터: 계절 변경 시 그리드 아이템이 해당 계절 데이터로 교체.
카테고리 드롭다운: "옷장/코디/스타일 일지" 3개 탭 전환 자리표시자(다른 화면으로 이동하는 상위 탭 구조로 추정 — 실제 내비게이션 로직은 별도 확인 필요).
드롭다운(카테고리/계절)은 상호 배타적으로 하나만 열림.
스크롤에 따라 그리드 상단 마스크 페이드 위치가 동적으로 이동(스크롤값 기반 계산).
4. 비주얼 스타일
폰트: Pretendard, fallback Noto Sans KR
배경: 웜 베이지 그라디언트(#F7F6F3 → #EDE9E1), 우상단에 은은한 세이지(#C5D3C7) 라디얼 틴트
헤더 필/버튼: 반투명 유리 느낌(backdrop-filter blur+saturate, rgba(247,246,243,0.38) 배경, 얇은 화이트 보더, soft shadow)
primary 컬러: #394550(네이비 슬레이트) — 선택 상태, FAB 배경
error 컬러: #A34B50(삭제 버튼), warning: #B98A3D(미완성 배지)
타일 배경: 이미지 있으면 실사진, 없으면 placeholder 스트라이프 4색 순환
코너 반경: 폰 프레임 44px, 필 버튼 100px(pill), 드롭다운 패널 16px
5. 데이터 모델 (참고용 목데이터 구조)
아이템: { id, label, season(겨울/봄가을/여름), incomplete? }

계절별 필터링, 각 아이템 카드에 라벨(영문 소문자, 의류 종류) 표시
"미완성" 플래그가 있는 아이템은 배지 노출(옷 정보 입력이 덜 끝난 상태로 추정)
6. 누락/확인 필요 사항 (개발자 확인 요망)
최우측 원형 "◎" 버튼의 실제 기능 미정 (레이아웃 참고용 자리표시자)
카테고리 탭 전환("코디", "스타일 일지") 시 실제 라우팅 대상 미정
아이템 탭(비선택 모드) 시 상세 화면 이동 여부 미정 — 현재는 선택 모드에서만 onTap 동작
"여러 장 추가"/"한 장 추가" 각각의 후속 플로우(업로드 UI 등) 미정
