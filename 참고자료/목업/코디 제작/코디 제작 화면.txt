코디 제작 화면 — 프론트엔드 개발 핸드오프
1. 화면 개요
옷 아이템을 조합해 "코디"(outfit)를 만드는 편집 화면. 상단 아트보드(캔버스) + 하단 옷장 바텀시트 2단 구조. 390×844 기준.

2. 레이아웃 구조 (상→하)
상태바(9:41 등) — 표시용
상단 네비게이션 바(고정, 54px):
좌: "취소" 텍스트 버튼
중앙: "코디 이름" 입력 필드(placeholder, 텍스트 입력 가능, 중앙 정렬)
우: "?" 도움말 원형 버튼 + "✓" 저장 원형 버튼(primary 배경)
스크롤 영역(네비 바 아래, 하단 시트 위 — 시트 높이에 따라 bottom 값 가변):
아트보드: 정사각형 캔버스, 좌우 엣지-투-엣지. 옷 아이템들이 절대 위치 + 회전값으로 콜라주처럼 배치(현재 목업엔 top/bag 2개, 회전 -7°/5°, 그림자 있음). 우하단에 원형 "배경지 색 선택" 버튼.
"사용된 옷 (N)" 라벨 + 가로 스크롤 캐러셀: 아트보드에 배치된 아이템 썸네일들 + 끝에 "+" 추가 버튼
하단 바텀시트(옷장 선택 패널, 접기/펼치기 가능):
드래그 핸들(탭하면 토글, 펼침 360px / 접힘 76px, 애니메이션 0.25s)
툴바: "계절 ▾ / {현재계절} ▾" 세그먼트 필(탭 시 계절 순환 전환) + 밀도 전환 원형 버튼(▦→▥→▢)
펼침 상태일 때만: 옷장 아이템 그리드(밀도에 따라 컬럼 수 변경), 첫 칸은 "+"(옷장에서 추가) 버튼, 나머지는 보유 아이템 썸네일(라벨 표시)
홈 인디케이터 바(최하단)
3. 인터랙션 / 상태
코디 이름 입력: 텍스트 필드, 자유 입력.
바텀시트 토글: 핸들 탭 → 펼침/접힘 전환. 접히면 위 스크롤 영역이 늘어남(bottom 값 연동, transition).
계절 전환: 탭할 때마다 전체→봄/가을→여름→겨울 순환. (옷장 그리드가 계절별로 필터링될 것으로 추정 — 현재 목업은 필터 로직 없이 고정 목데이터 노출)
밀도 전환: 옷장 그리드 컬럼 수 4/2/1 순환.
"+" (사용된 옷 캐러셀 끝): 아이템 추가 진입점 — 동작 미정
옷장 그리드의 "+": addFromWardrobe — 현재 빈 함수(no-op), 실제로는 탭한 옷장 아이템을 아트보드에 추가하는 동작으로 추정
배경지 색 선택 버튼: toggleBgPicker — 현재 빈 함수(no-op), 색상 선택 UI 오픈 예정으로 추정
저장(✓) / 취소: 현재 동작 없음 — 실제 저장/네비게이션 로직 필요
도움말(?) 버튼: 동작 없음 — 툴팁/가이드 오픈 예정으로 추정
4. 아트보드(캔버스) 상세 — 중요
정사각형, 컨테이너 좌우 8px 마진(엣지-투-엣지에 가깝게)
아이템은 절대 위치(top/left)와 회전(transform: rotate)으로 자유 배치 — 드래그로 재배치, 회전, 크기 조절, 레이어 순서(z-index) 변경 등 실제 인터랙션 사양은 목업에 없음. 개발자 확인 필요
각 아이템 카드: 둥근 사각형, 그림자, 좌하단 소문자 영문 라벨 배지
배경은 은은한 그라디언트 + surface 컬러(추후 사용자가 선택한 "배경지 색"으로 대체될 것으로 추정)
5. 비주얼 스타일
폰트: Pretendard, fallback Noto Sans KR (옷장 메인과 동일)
primary: #394550(네이비 슬레이트), accent: #C5D3C7(세이지) — top 아이템 강조색
배경 그라디언트: #F7F6F3 → #EDE9E1 (옷장 메인과 동일 톤)
바텀시트: 상단 모서리만 24px 라운드, 위쪽 그림자로 콘텐츠 위에 떠 있는 느낌
아이템 카드 라운드: 16~18px, 옷장 그리드 아이템은 각짐(0 radius, 옷장 메인과 통일)
6. 데이터 모델 (참고용 목데이터 구조)
usedItems: { label, bg, labelColor } — 아트보드에 배치된 아이템(현재 위치/회전 값은 하드코딩, 실제로는 각 아이템별 좌표/회전 데이터 필요)
wardrobeItems: { label, bg, labelColor } — 바텀시트 그리드 목록(옷장 메인 화면과 동일한 아이템 소스로 추정, 연동 필요)
7. 옷장 메인 화면과의 연계 (개발자 확인 필요)
옷장 메인의 "+ FAB → 코디 여러 장 추가" 또는 옷장 아이템 선택에서 이 화면으로 진입하는 흐름으로 추정
저장 시 옷장 메인 하단 "적용한 코디" 캐러셀(스타일 일지 상세 화면 참고)에 반영되는 것으로 추정 — 실제 데이터 연동 플로우 확인 필요
8. 누락/확인 필요 사항 종합
아트보드 내 아이템 드래그/회전/리사이즈/삭제 인터랙션 전체
"배경지 색 선택" 버튼의 실제 색상 피커 UI
저장(✓)/취소 버튼의 실제 동작 및 네비게이션 대상
옷장 그리드 아이템 탭 시 아트보드 추가 로직(현재 no-op)
계절/밀도 필터가 실제 사용자 옷장 데이터에 어떻게 연동되는지
"?" 도움말 버튼 콘텐츠
