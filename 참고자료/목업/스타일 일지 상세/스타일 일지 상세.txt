스타일 일지 상세 화면 — 프론트엔드 개발 핸드오프
1. 화면 개요
특정 날짜의 스타일 기록(사진+메모+착용 코디)을 조회하는 상세 화면. 390×844 기준, 사진 아트보드 + 스크롤 콘텐츠 구조.

2. 레이아웃 구조 (상→하)
상태바(9:41 등) — 표시용
상단 좌측: "스타일 일지 ▾" 필 버튼(카테고리 드롭다운 트리거)
상단 우측: "···" 원형 더보기 버튼
카테고리 드롭다운(옷장/코디/스타일 일지 3항목, 활성 항목 도트) — 옷장 메인과 동일 컴포넌트
더보기 드롭다운: "수정하기" / "공유하기" / "삭제하기"(빨간색 텍스트) 3항목
헤더 아래 상단 페이드(스크롤 시 위로 콘텐츠가 더 있음을 알리는 그라디언트, 스크롤 위치에 따라 opacity 전환)
스크롤 콘텐츠 영역:
사진 아트보드: 폭 100%(엣지-투-엣지), 높이 380px, 이미지 슬롯(사용자가 사진 드래그로 채움)
슬라이드 인디케이터 점 4개(현재 2번째 활성 — "적용한 코디 콜라주 슬라이드"가 고정 2번째 슬라이드라는 설명은 하단 캡션 참고. 슬라이드 스와이프 자체는 목업에 구현 안 됨, 점만 표시)
"적용한 코디" 라벨 + 가로 캐러셀(사용된 아이템 칩들 + "코디+" 추가 버튼) — 스크롤바 숨김, 좌우 끝 도달 시 사라지는 반투명 쉐브론(‹›) 인디케이터로 스크롤 가능 여부 표시
날짜 · 위치 메타 정보 한 줄
"메모" 라벨 + 본문 텍스트 박스(줄바꿈 유지, 좌측 테두리 없는 사각 카드)
하단 페이드(스크롤 시 아래로 콘텐츠가 더 있음을 알리는 그라디언트)
HUD 스크롤바: 평소 숨김, 스크롤 중에만 우측 끝에 얇게 노출(빠르게 페이드인, ~0.9초 후 서서히 페이드아웃), 상하 마진 동일하게 화면 전체 길이로 배치
좌하단: 뒤로가기 원형 버튼(←, primary 배경)
홈 인디케이터 바(최하단)
3. 인터랙션 / 상태
카테고리 드롭다운: "옷장/코디/스타일 일지" 탭 전환 자리표시자 — 실제 라우팅 대상 미정
더보기 메뉴: 항목 선택 시 현재는 메뉴만 닫힘(no-op) — 수정/공유/삭제 각각 실제 동작 필요
"적용한 코디" 캐러셀: 가로 스와이프 가능, 칩 탭 시 해당 코디로 이동 예정("코디+" 버튼 onGoToOutfit은 현재 빈 함수(no-op))
메인 세로 스크롤: 스크롤 위치에 따라 상/하단 페이드 및 우측 HUD 스크롤바 표시 로직 연동(스크롤 시작 시 페이드인, 정지 후 0.9초 뒤 페이드아웃)
카테고리/더보기 드롭다운은 상호 배타적으로 하나만 열림
4. 비주얼 스타일
폰트: Pretendard, fallback Noto Sans KR (다른 화면과 동일)
헤더 필/버튼: 반투명 유리 느낌(backdrop-filter blur+saturate) — 옷장 메인과 동일 컴포넌트 재사용
primary: #394550(네이비 슬레이트) — 뒤로가기 버튼, 활성 슬라이드 점
error: #A34B50(삭제하기 텍스트)
사진 아트보드는 그림자 없이 각진 엣지-투-엣지, 메모 카드는 라운드 4px(다른 카드류보다 각짐)
HUD 스크롤바: 두께 3px, 저채도(rgba(43,45,48,0.5)) — 존재감 최소화
쉐브론 인디케이터: 저투명도(opacity 0.35), 배경/버튼 스타일 없음, 캐러셀 콘텐츠 영역 내 수직 중앙 정렬
5. 데이터 모델 (참고용 목데이터 구조)
사진: 사용자 업로드 이미지(현재 목업은 드래그앤드롭 플레이스홀더)
slideDots: 슬라이드 개수(현재 4 고정) + activeSlide 인덱스 — 실제 슬라이드 콘텐츠/스와이프 로직 없음, 목업은 두 번째 점만 활성 표시
usedItems: { label, bg, labelColor } — 적용한 코디에서 사용된 아이템 목록(코디 제작 화면과 동일 소스로 추정)
logDate: 날짜 문자열("2026.07.03")
logLocation: 위치 문자열("서울")
memoText: 자유 텍스트(줄바꿈 포함)
6. 다른 화면과의 연계 (개발자 확인 필요)
"적용한 코디" 칩/코디+ 버튼 → 코디 제작 또는 코디 상세 화면으로 이동하는 흐름으로 추정
카테고리 드롭다운의 "코디" 탭 → 코디 목록/제작 화면, "옷장" 탭 → 옷장 메인으로 이동 추정
7. 누락/확인 필요 사항 종합
사진 슬라이드(점 4개)의 실제 스와이프 콘텐츠 및 각 슬라이드가 무엇을 보여주는지(현재는 2번째=코디 콜라주라는 설명만 캡션에 존재, 나머지 3개 슬라이드 정의 없음)
더보기 메뉴 "수정하기/공유하기/삭제하기" 각각의 실제 동작 및 확인 다이얼로그 필요 여부
"코디+" 버튼 및 코디 칩 탭 시 실제 이동 대상
사진 업로드/교체 플로우(현재는 정적 플레이스홀더)
메모 텍스트 편집 가능 여부(현재 읽기 전용으로 목업됨 — "수정하기" 메뉴와의 관계 확인 필요)
