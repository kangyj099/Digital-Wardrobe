# 옷장 정리 앱
> ver 0.0.0
>
> [프로젝트 상세정보 노션 페이지 링크](https://app.notion.com/p/0-1v-3901d57dc5a680fca775ff3916a53ea9?source=copy_link)
**디지털 옷장** — 옷 사진을 AI로 자동 정리하고, 실제 착용한 코디를 기록해서 다시 꺼내볼 수 있는 모바일 옷장 앱

개인적 필요를 느껴 1인 개발로 시작 → 니치 서비스 정식 출시 목표



### 개발 정보
* 작업 기간 : 2026.07.01~개발중
* 작업 방식 : 클로드 코드를 활용한 vibe 코딩을 메인으로 함
* 개발 형태 : 1인개발
* 핵심 차별점 : 실제 착용한 코디를 기록/회고하는 기능
* 사용 환경 : IOS, Android 모바일 (Flutter 크로스플랫폼)
* 클라이언트 기술 : Flutter (Dart)
