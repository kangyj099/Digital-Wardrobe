- 슬라이드 1~4까지 1920×1080으로 제작해둔 상태에서 멈춤
- 중단 사유 두 가지:
  1. Figma MCP 호출 한도 소진 (Starter 플랜 월 6회, 4/6 사용 후 슬라이드 5 작업 중 소진)
  2. **규격 불일치** — 스펙(`figma-slide-prompt-final.md` §6)이 A4로 바뀌었는데
     Figma Slides는 슬라이드 크기가 1920×1080으로 고정되어 있고 `slide.resize()`가 동작하지 않는다

이관은 한도가 리셋된 뒤에 시작한다. 그 전에 스크립트를 전부 작성해두면 호출 4회로 끝난다.

## 결정 (2026-08-10)

**Slides 파일을 그대로 쓰되, A4 영역을 가운데 두고 좌우를 배경색으로 채운다(필러박스).**

- Slides의 1920×1080은 고정이고 `slide.resize()`가 동작하지 않는다. 그래서 슬라이드 자체를
  A4로 만들 수는 없다. 대신 **콘텐츠 영역만 A4 비율로 잡고** 남는 좌우를 배경으로 채운다.
- 슬라이드 배경을 HTML과 같은 그라디언트(`#EEEAE1 → #E6E0D3`)로 깔면 좌우 여백이
  잘린 것처럼 보이지 않고 의도된 여백으로 읽힌다.
- 발표 모드·슬라이드 그리드를 그대로 쓸 수 있고, 기존 파일과 슬라이드 8개도 재사용된다.

### A4 영역 좌표

| 항목 | 값 |
|---|---|
| 슬라이드 | 1920 × 1080 (고정) |
| A4 콘텐츠 영역 | **1527 × 1080** (= 1080 × √2, A4 가로 비율) |
| 좌우 여백 | 각 **196.5px** — A4 영역 x 원점 = 196.5 |
| HTML → Figma 배율 | **1527 / 1123 = 1.36** |
| `.inner`(1035×706) 대응 | 1408 × 960, 원점 (256.4, 60) |

HTML의 모든 좌표·폰트 크기에 **1.36을 곱하고 x에 196.5를 더하면** 그대로 대응된다.
예: HTML의 `.h-title` 30px → Figma 40.8px, inner 기준 x=0 → 슬라이드 기준 x=256.4.

여백 처리는 둘 중 하나다. A4 경계를 굳이 보여줄 이유는 없으니 1번을 권한다.

1. 슬라이드 전체에 그라디언트 배경만 깔고 콘텐츠를 가운데 정렬 — 경계선 없음
2. A4 영역에만 살짝 다른 톤/그림자를 줘서 "종이"처럼 보이게 — 인쇄물 느낌이 필요할 때

## 이관 절차

HTML이 이미 좌표까지 확정된 명세 역할을 한다. `preview.py`로 뽑은 PNG를 옆에 띄워두고
같은 배치를 1.36배로 재현하면 된다.

### MCP 호출 예산

Starter 플랜은 월 6회다. **파일을 직접 만들어 URL을 주면 `create_new_file` 1회가 절약된다.**
기존 파일(`rnwkizzMrVKO5gjg7YaqKR`)을 재사용하면 새로 만들 필요조차 없다 — 슬라이드 8개가
이미 있으므로 그 위에 덮어쓰면 된다.

| # | 호출 | 내용 |
|---|---|---|
| 1 | `upload_assets` | 앱 스크린샷 3장 한 번에 |
| 2 | `use_figma` | 배경·A4 영역 + S1~S4 |
| 3 | `use_figma` | S5~S8 + 하단 인디케이터 8장 일괄 |
| 4 | `use_figma` | 검증 (겹침 / 텍스트 잘림 / 슬라이드 밖 노드) |

**4회.** 2회가 예비로 남는다. 배치를 더 쪼개면 예비가 줄어드니 쪼개지 않는다.
스크립트는 호출 전에 전부 작성해두고, 색상 팔레트와 폰트 로딩 프리앰블은 매 스크립트 상단에
그대로 복붙한다.

> 기존 슬라이드 1~4는 1920×1080 풀블리드로 만들어져 있어 A4 영역 기준과 맞지 않는다.
> 재사용하려면 좌표를 다시 잡아야 하므로, 사실상 8장 전부 다시 그린다고 보면 된다.
> 파일과 슬라이드 노드만 재사용하는 것이다.

### 그 밖에 걸렸던 것들

- **폰트**: Pretendard는 Figma에 설치돼 있지 않아 **Noto Sans KR**만 쓸 수 있다
  (Black / Bold / Medium / Regular). 텍스트를 건드리기 전에 `loadFontAsync`를 `await` 해야 한다.
  HTML 쪽 weight 800은 Noto Sans KR Black, 700은 Bold, 600은 Medium으로 대응시킨다.
- **이미지**: `upload_assets`로 올린다. 반환된 `submitUrl`에 PNG 원본 바이트를 POST해야
  업로드가 완결된다. 한 번에 3장을 올려 호출 수를 아낀다.
- **그림자 2겹**: 디자인 토큰의 `0 2px 10px rgba(43,45,48,.06)` + `inset 0 1px 0 rgba(255,255,255,.16)`은
  Figma에서 `DROP_SHADOW` + `INNER_SHADOW` 두 개의 이펙트로 나눠 넣는다.
- **프로스티드 글래스**: `backdrop-filter: blur(3px) saturate(180%)`는 Figma의
  `BACKGROUND_BLUR` 이펙트로 근사한다. saturate 대응물은 없으니 반투명 fill 쪽을 조금 진하게 잡는다.
- **점선 테두리**: 플레이스홀더 박스는 `strokes` + `dashPattern: [6, 4]`.
