프로젝트 개요

01

Needs

① 옷 파악 · 관리의 니즈 필수 옷 / 신발이 너무 많아서 "뭘 가졌는지, 어디 있는지" 파악이 어려움 ☞ MVP의 '옷장'으로 연결
② 코디 기억 · 취향 파악의 니즈 리텐션 매번 비슷한 옷만 입고, 과거 스타일링 기록도 전혀 안 남음 ☞ MVP의 '스타일 일지'로 연결
02

Persona

제작자 본인 — 옷과 신발이 지나치게 많다! + 정리 취약형 사람

"가진 것 / 자주 입는 것 / 잘 어울렸던 것"을 기억이 아닌 기록으로 남기고 싶어함

03

MVP 요약

앱다운 UX 철학

'웹을 감싼 앱'이 아닌 진짜 앱을 만들기 위한 디자인 · 기능 선택

01

화면 여백을 지키는
가벼운 UI

불투명 고정바 대신 반투명 글래스 + 플로팅 버튼을 사용해, 작은 모바일 화면에서도 콘텐츠 영역을 최대한 확보하고 답답하지 않게 설계

실제 적용 — 스크롤 시 콘텐츠 경계까지 따라 올라오는 글래스 헤더
02

탭을 통한
유기적인 연결

보이는 값 / 이미지가 곧 링크. 궁금하면 정보 확인, 정보-터치 직관적 이동. 화면은 읽고 끝나는 게 아니라 항상 상호작용 가능해야 한다는 원칙

값 = 링크읽기 → 탐색막다른 화면 없음
