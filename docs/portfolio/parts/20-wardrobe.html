RETENTION CORE

스타일 일지

그날 입은 착장을 사진으로 남기고, 그 안의 아이템을 옷장 데이터와 연결한다. 일지는 사진첩이 아니라 옷장의 사용 기록이 된다.

일지 기록→옷장 아이템 연결→착용 이력 자동 집계

어떤 옷을 자주 입고 어떤 옷을 안 입는지가 별도 입력 없이 쌓인다. 취향과 사용 빈도를 실제 데이터로 확인할 수 있다.

고정 바 대신 콘텐츠 위에 떠 있는 UI
01

화면 여백을 지키는 가벼운 UI

작은 모바일 화면에서 콘텐츠 영역을 최대한 확보하기 위해 불투명한 고정 바를 최소화하고, 반투명 Glass UI와 플로팅 버튼을 선택했다.

UI가 콘텐츠를 차지하지 않고 콘텐츠 위에 가볍게 존재하도록 설계
02

탭을 통한 유기적인 연결

보이는 값과 이미지가 곧 다음 정보로 연결된다. 사용자가 궁금한 것을 발견하면 그대로 다음 행동으로 이어진다.

탭→ 정보 확인→ 관련 화면 이동
화면은 읽고 끝나는 것이 아니라, 항상 다음 행동으로 연결될 수 있어야 한다
03

모바일 네이티브 제스처 지원

swipe · long-press를 기본 조작으로 두되, 같은 동작을 수행하는 버튼을 항상 함께 노출한다.

제스처 중심이지만, 제스처를 강요하지 않는다
