# 5단계: 디자인 시스템 사전 체크리스트 (하이파이 진입 전)

## A. 사용성 원칙 (Nielsen 휴리스틱) 감사

| 원칙 | 상태 | 비고 |
|---|---|---|
| 시스템 상태 가시성 | 부분 반영 | AI 로딩/재시도, 스크롤 힌트 있음. 저장/삭제 등 조용한 액션의 피드백 전수 점검 필요 |
| 친숙한 용어/개념 | 반영됨 | 옷장/코디/스타일 일지 등 일상어, 실물 은유 아이콘 |
| 실행취소/제어권 | 반영됨 | 휴지통+복원, 상시저장, 코디 만들기 Undo |
| 일관성 | 강하게 반영됨 | 기능 재사용, 공용 네비, 정렬기준표 공통화, 삭제 진입점 통일 |
| 오류 방지 | 반영됨 | 바인딩 뎁스 제한, 미완성 항목 바인딩 불가, 개행 불허 등 |
| 인식 > 회상 | 반영됨 | 드롭다운 메뉴, 플레이스홀더, 태그 노출 |
| 유연성/효율성 | 부분 반영 | 검색/정렬 있음, 파워유저 제스처는 미정 |
| 심미성/미니멀리즘 | 철학 확립 | 실제 비주얼은 하이파이에서 확정 |
| 오류 인지/복구 | 부분 반영 | AI 실패 재시도 팝업 있음, 에러 카피 톤은 미정 |
| 도움말/문서 | **반영 예정** | 코디 만들기/옷 추가하기에 "?" 코치마크(MVP) + 가이드 패널(Phase 3) |

## B. 접근성 원칙 감사

| 원칙 | 상태 |
|---|---|
| 충분한 색 대비 | 미정 — 팔레트 확정 시 WCAG AA(4.5:1) 체크 |
| 색만으로 정보 전달 금지 | 반영됨 (배지+텍스트 조합) |
| 가독성 높은 텍스트 크기 | 아래 F 타이포 스케일 참고 |
| 키보드 네비게이션 | Phase 2~3 |
| 발작 유발 요소 지양 | 현재 위반 없음 |
| 터치 타겟 44×44px 이상 | 와이어프레임 대부분 반영, 하이파이 전수 검증 필요 |
| 예측 가능성 | 반영됨 |

## C. 디자인 시스템 10항목 현황

| 항목 | 상태 |
|---|---|
| 1. 무드 조정 | 미정 — 레퍼런스 대기 중 |
| 2. 비주얼 컨셉 정의 | 미정 |
| 3. 그리드/마진 규칙 | 아래 F 참고 |
| 4. 컬러 팔레트 정의 | 아래 E 참고 |
| 5. 타이포그래피/위계 | Pretendard + 시스템 폰트 전환 옵션, 스케일은 F 참고 |
| 6. 아이콘 일관성 | 사실상 결정됨 — Tabler Icons 일관 사용 중 |

| 8. 컴포넌트 스타일 | 부분 반영 — 라운드 코너, 필 버튼, 바텀시트 패턴 반복 사용 중 |
| 9. 그래픽 톤 정의 | 미정 |
| 10. 다크모드 대응 규칙 | 지원 원칙 결정, 구체 규칙은 미정 |

## D. 배경색 방향 (확정)
화면 배경과 카드/타일 배경을 미묘한 톤 차이로 분리 — 배경 제거된 옷들의 제각각인 실루엣을 통일된 캔버스로 묶어주는 효과. 차이가 미묘해야 하며(강한 대비는 노이즈가 됨), 정확한 값은 E 컬러 팔레트에서 확정.

## E. 컬러 팔레트 (초안)

방향성: UI는 거의 무채색으로 절제, 옷 사진이 화면의 색을 담당. 포인트 컬러 하나만 절제된 톤으로. 웜톤 뉘앙스로 차갑고 사무적인 느낌 피함.

| 용도 | 라이트 모드 | 다크 모드 |
|---|---|---|
| 화면 배경 | #FAFAF8 | #17161B |
| 카드/타일 배경 | #F2F1EC | #201F26 |
| 테두리 | #E7E5DE | #34323B |
| 보조 텍스트/아이콘 | #6E6B63 | #A8A5AD |
| 기본 텍스트 | #2B2924 | #F2F0EC |
| 포인트(주요 버튼·선택 상태) | #B9603F (뮤트 테라코타) | 동일 색상, 배경 대비만 조정 |
| 경고/영구삭제 | #B5453D | 동일 계열, 명도만 조정 |

테라코타를 포인트로 제안하는 이유: 파랑 계열은 대부분의 앱이 쓰는 기본값이라 개성이 없고 패션 도메인과도 안 어울림. 테라코타는 가죽·클레이 톤과 맞닿아 패션/라이프스타일 앱에 자연스럽고, 채도를 낮추면 튀지 않으면서 앱만의 색이 됨. 대안: 남색 계열(#3A4A5C) — 더 차분하고 클래식한 느낌.

## F. 간격 · 타이포그래피 스케일 (초안)

**간격 스케일**
| 토큰 | 값 | 용도 |
|---|---|---|
| space-1 | 4px | 아이콘-텍스트 최소 간격 |
| space-2 | 8px | 타일 그리드 갭 |
| space-3 | 12px | 컴포넌트 내부 패딩 |
| space-4 | 16px | 화면 좌우 여백(기본) |
| space-5 | 24px | 섹션 간 간격 |
| space-6 | 32px | 큰 블록 간 간격 |

**모서리 반경**
| 토큰 | 값 | 용도 |
|---|---|---|
| radius-pill | 999px | 필터 칩, 토글 |
| radius-sm | 8px | 작은 썸네일/타일 |
| radius-md | 12px | 카드, 버튼, 입력 필드 |
| radius-lg | 20px | 바텀시트 상단, 모달 |
| radius-xl | 32px | 폰 프레임(목업용) |

**타이포그래피 스케일** (Pretendard 기준)
| 토큰 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| title | 16px | Medium(500) | 헤더 컨텐츠명, 코디 이름 |
| subtitle | 15px | Medium(500) | 화면 제목, 아이템명 |
| body | 13px | Regular(400) | 본문, 필드 값 |
| caption | 12px | Regular(400) | 태그, 날짜, 메타 정보 |
| micro | 11px | Regular(400) | 배지, 카운터 |

줄간격 1.4~1.5 권장, 최대 굵기 Semibold(600)까지만 사용
