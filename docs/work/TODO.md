- **Bash PreToolUse 훅(`guard_git_actions.py`)의 상대경로 자기잠금 근본 수정** (2026-07-13). 이 훅이 `python .claude/hooks/guard_git_actions.py`로 상대경로 등록돼 있어서, Bash 세션 cwd가 저장소 루트를 벗어나는 순간(`cd` 하나만 섞인 명령이라도) 그 뒤 모든 Bash 호출이 훅 스크립트를 못 찾고 즉시 막힌다 — `cd`로 되돌아가는 시도조차 같은 훅에 걸려 막혀서 세션 안에서 복구 수단이 없음(2026-07-13 실측: `pwd`/`echo` 같은 무해한 명령도 전부 차단됨). 훅 커맨드를 절대경로로 등록하거나 스크립트가 `__file__` 기준으로 자기 위치를 해석하도록 고치면 이 클래스의 자기잠금이 원천 차단된다 — 다만 `.claude/settings.json` 수정이라 일반 Edit 승인 절차를 거쳐야 함. 급하진 않음: 세션이 끝나면 다음 세션은 새 셸(cwd=루트)로 시작해 저절로 풀리고, 당장의 예방책(Bash에서 `cd` 대신 절대경로나 Glob 사용)은 이미 관례로 알고 있음 — 훅 자체의 견고성 개선은 우선순위 낮은 안정성 항목으로 파킹. (2026-08-03 재확인: worktree 정리 중 이 훅 스크립트 파일 자체가 삭제되며 실제로 재발 — 이번엔 파일을 Write로 복구해 해소.)
