# 1. 옷장

## 옷장 메인/목록 (Main형)

- 두 손가락 핀치 제스처로 갤러리 타일 크기 조절 + 분류 버튼 오른쪽 타일 크기 전환 버튼
    
    버튼 아이콘은 탭할 때마다 큰 정사각 1열 → 2×2 → 4×4 아이콘으로 순환하지만, 이는 밀도 단계를 상징하는 아이콘일 뿐 실제 컬럼 수는 최소-중간-최대 3단계로 매핑됨(구체적 컬럼 개수는 디자인 원칙 문서에서 정의)
    
- 상단 플로팅바: `현재 선택한 분류 기준 ▼ | 현재 보고 있는 분류 ▼` (분류 기준이 '전체 보기'면 두 번째 버튼 숨김)
- 분류 그룹 클릭 → 목록 진입, 분류 기준 바꾸면 그룹 보기로 복귀
- 우하단 [+] 버튼: 전체보기에서는 [한 장 추가하기 / 여러 장 추가하기], 특정 분류를 보는 중엔 [이 분류에 한 장 추가하기 / 이 분류에 여러 장 추가하기]로 라벨 전환 (자동 태그 적용)
- 옷 터치 시 약간의 반응 애니메이션 후 상세 화면 전환
- 텍스트 검색, 정렬 옵션(최신순/착용빈도순 등) 지원

## 옷 추가하기 (Add/Create형)

- 갤러리에서 사진 선택. 이미 앱에 등록 완료한 사진은 시각적으로 표시(딤 처리 등)
- **한 장 추가하기**: 이미지 편집기(자르기/회전/확대축소/마스킹 붓) + 자동 마스킹 버튼(상단 중앙) → 배경 제거 후 자동 중앙 크롭
    - 필드 입력 단계에서는 옷 이미지가 상단에 고정되고, 그 아래로 필드들이 스크롤됨.
    이미지 영역 우하단에 편집 아이콘을 두어 필드 입력 중에도 언제든 이미지 편집으로 재진입 가능
    - 기본 필드(종류/색상/사이즈/계절/위치/메모) 노출, [정보 추가]로 브랜드/구매처/구매가 추가
    - 자동 태깅된 대표 태그는 수정 가능, 내부 메타데이터는 비공개
    - 우상단 V버튼 또는 하단 [옷 추가 완료] 버튼으로 저장
    - 저장 후 옷장으로 복귀 애니메이션, 추가한 옷이 있는 위치로 자동 스크롤
- **여러 장 한 번에 추가하기**: 여러 사진 선택 → 자동 배경제거+자동태그로 일괄 저장 → 이후 개별 수정 가능. 진행률 모달(프로그레스바), 중간 취소 시 완료분까지만 유지
- 헤더에 "?" 아이콘 → 코치마크 팝오버(MVP), [자세히 보기] → 가이드 워크스루 패널(Phase 3)

### 옷 상세 (Detail형)

- 상단 이미지 (핀치 확대/축소, 터치 시 전체화면)
- 하단 주요 태그(접힘/더보기), 위치/메모
- 코디:가로캐러셀. 연결된 코디 없을 경우 첫 칸에 + 타일 배치하여 코디 제작 화면으로 넘어갈 수 있게 함.
- 스타일일지:갤러리형태, 기본 2열 배치이나 1장만 있을 경우 1열배치로 변경. 연결된 스타일 일지 없을 경우 + 타일 배치하여 스타일일지 제작 화면으로 넘어갈 수 있게 함
- 착용 카운트, 마지막 착용일 표시
- 삭제 시 확인 절차 + 임시 휴지통
