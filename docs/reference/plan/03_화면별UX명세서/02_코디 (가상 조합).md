# 2. 코디 (가상 조합)

## 코디 메인 (Main형)

- 옷장과 동일한 레이아웃/버튼 패턴 (분류 그룹화, 핀치 줌 등)
- 우하단 [+] 버튼: 옵션 없이 바로 코디 만들기로 진입 (1개씩만 생성)
- 특정 분류를 보고 있을 때 + → 해당 분류 태그 자동 적용, 라벨 [이 분류로 코디 만들기]로 전환
- 기본 1:1 아트보드 (변경 가능성 있음),  정렬/필터에 날씨·계절 기준 지원(스타일 일지와 공통)

> (Phase 2) 기존 코디를 레퍼런스로 삼아 새 코디를 만드는 편의 기능
> 

## 코디 상세 (Detail형)

- 상단 아트보드: 계절/날씨/태그/분류 표시, 공란은 [+] 버튼으로 대체되며 즉시 수정 가능
- 아트보드에서 옷이 겹친 영역 터치 → 대상 선택 팝업 → 선택한 옷 영역에 상호작용 반영
- 아트보드의 옷 터치 → 하단 옷 목록에서 해당 옷 위치로 스크롤 + 강조 표시 (테두리 등)
- 아트보드의 옷 길게 누르기(1~2초) → 코디 만들기(편집) 화면 진입
- 하단: 사용된 옷 목록(가로 스크롤) → 연결된 스타일 일지 목록(기본 2열, 1장이면 1열, 정사각형 타일)
- 연결된 스타일 일지 없으면 [+] 슬롯 → 스타일 일지 리스트 모달(하단 시트, 옷장 모달과 동일 작동 방식). 여기서 새 스타일 일지를 만들 수도 있는데(1단계 바인딩), 그렇게 만들어진 스타일 일지의 코디 슬롯은 **선택만 가능**하고 새로 만들 수는 없음(바인딩 뎁스 제한)
- **자동 매칭(초기 세팅용, 지속 동기화 아님)**: 코디를 스타일 일지에 연결하면, 그 코디에 포함된 옷들이 스타일 일지의 착용 옷 목록에 자동 추가(중복 제외). 반대로 스타일 일지에 이미 등록된 착용 옷이 있는 상태에서 새 코디를 만들면, 그 옷들이 새 코디 아트보드에 기본 그리드 배치로 미리 올라간 채 시작 (이후 자유롭게 재배치/삭제 가능)
- 헤더 "⋯" 메뉴 → 삭제

## 코디 만들기 (편집) (Add/Create형, 편집)

- 상단바: 취소(좌) / **코디 이름 입력 필드** (중앙, 기존 "코디 만들기" 텍스트 위치) / 저장 V버튼(우)
    - 진입 시 흐린 색 플레이스홀더 "코디 이름" 노출, 공란이 되면 언제든 재노출
    - 미포커스 상태에서 텍스트가 넘치면 말줄임(...), 터치해 포커스하면 박스가 가로/세로로 확장되어 전체 내용 표시(자동 줄바꿈, 개행 직접 입력은 불허)
    - 공백/특수문자 허용, 최대 40자 (근접 시 카운터 노출 권장)
    - 미입력 상태로 저장 시 "YYYY-MM-DD 시:분:초"로 자동 지정
- 상단 1:1 아트보드 고정, 하단은 옷장 갤러리를 팝업 시트로 배치
    - **바텀시트 기본 크기**: 키패드 정도의 중간 높이로 시작 (충분히 스크롤 가능)
    - 옷을 하나 추가하면 자동으로 얇은 핸들바 상태로 접힘 (편집에 방해되지 않게), 핸들바를 위로 드래그하면 재확장
    - 완전히 접힌 상태에서는 위쪽 꺾쇠(∧) + 옷 아이콘으로 "당기면 옷 목록이 열린다"는 것을 암시 (하이파이 단계에서 적용)
- 옷장 모달에서 옷 추가도 가능, 추가한 옷은 자동으로 아트보드에 선택 배치
- **아트보드 모서리에 배경색 스와치 컨트롤** (현재 배경색 표시, 터치 시 변경) — 바텀시트(추가할 아이템)와 역할을 분리: "추가하는 것"은 시트에서, "보드 자체 설정"은 보드에서. MVP는 흰색/회색/검은색 단색만 지원
    - (Phase 2) 스티커 등 꾸밈요소 추가 시, 바텀시트에 [옷 | 스티커] 탭 도입 예정. 꾸밈요소는 하단 "사용된 옷 목록" 스트립에는 노출하지 않음(옷만 노출). 삭제는 보드 밖으로 드래그 또는 별도 숨겨진 레이어 리스트로 관리 (검토 필요)
- 아트보드 아이템: 이동, 회전, 크기 변경, 렌더순서(z-index) 변경
- 렌더순서 변경: 겹친 영역 터치 → 컨텍스트 메뉴(팝업)로 겹친 이미지 리스트 → 드래그로 순서 재배열
- 겹친 이미지 이동 시 기본은 최상단 옷, 아래쪽 옷은 컨텍스트 메뉴에서 선택 후 터치+드래그
- **하단 "사용된 옷 목록" 영역**: 고정 높이의 그리드(4열, 기본 2줄 노출) 안에서 세로 스크롤 (아트보드 위치는 고정, 이 영역만 내부 스크롤). 넘치면 스크롤 가능함을 그라데이션으로 힌트. 그리드 마지막 칸에 점선 + 타일 배치 — 터치 시 바텀시트 확장. 바텀시트가 확장되면 이 영역 위로 덮임
- **아이템 삭제**: 하단 옷 리스트에서 터치 → 우상단 X버튼 활성화 → 재터치로 삭제 / 아트보드에서 화면 바깥으로 드래그 시 햅틱 + 바깥 영역 딤드 처리 + 휴지통 아이콘 노출, 드롭 시 삭제
- **되돌리기(Undo)**: 직전 동작 취소 지원
- 우상단 V버튼 또는 하단 [코디 만들기] 버튼으로 저장
