# 3. 스타일 일지

## 스타일 일지 메인 (Main형)

- 공용 네비게이션 적용 (상단 헤더 컨텐츠 이름 드롭다운 + 좌하단 조건부 뒤로가기)
- 갤러리 형태, 코디/옷장과 동일한 레이아웃 패턴 (그룹화 없이 플랫한 갤러리)
- 정렬/필터
    
    날짜, 옷 종류, 날씨, 계절 기준 지원 (역순 보기 옵션 포함). 진입 시 항상 고정된 기본값(날짜 기준 최신순 · 전체 보기)으로 시작
    — 옷장/코디가 항상 루트(그룹 보기)로 시작하는 것과 동일한 "메뉴 진입 시 항상 고정 상태로 리셋" 원칙을 따름
    
- 우하단 [+] 버튼 → [1카드 추가 / 여러카드에 분할 추가]
- 1카드 추가 시 첫 선택 이미지가 자동으로 대표이미지 지정

## 스타일 일지 추가 (Add/Create형)

- 간단한 이미지 편집기 (비율 선택, 확대/축소, 회전만 — 배경제거 없음)
- 편집 완료 후 열람 화면으로 전환, 코디/옷 정보 바인딩은 열람 화면에서 진행

## 스타일 일지 열람 (Detail형)

- 공용 네비게이션 적용 (상단 헤더 컨텐츠 이름 드롭다운 + 좌하단 조건부 뒤로가기)
- 카드 구조: 대표이미지(1번, 고정) → 코디 슬롯(2번, 고정) → 추가 사진(3~10번, 최대 8장)
    - 슬롯 재배치: 사진을 꾹 눌러 스냅한 뒤 좌우로 끌면 인접 슬롯과 한 칸씩 순서가 바뀜. 1·2번(대표이미지/코디)은 고정이라 재배치 대상 아님.
    - 슬롯이 10칸 다 차기 전까지는, 내용이 있는 마지막 슬롯 다음 슬롯이 [+] 버튼으로 표시되어 그 자리에서 바로 사진을 추가할 수 있음.
- 이미지 좌→우 스와이프로 슬롯 간 이동
- 코디 슬롯 미연결 시 플레이스홀더로 [코디 +] 텍스트 표시, 슬롯 터치 시 연결 바텀시트로 연결(공통 규칙 "연결 바텀시트" 참고). 자동 매칭 규칙은 코디 섹션 참고
- 이미지 하단 착용 옷 목록(가로 스크롤) + 우측 끝 [+] 버튼으로 옷 추가
- 날짜/장소 정보 (갤러리 메타데이터 자동 입력, 수정 가능)
- (Phase 2) 메모 필드 (최대 1000자, 공백/개행만 있으면 "내용 없음"으로 간주해 저장 안 함)
