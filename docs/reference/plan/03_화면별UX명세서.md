- 레이아웃은 동일하게 유지하되 [+] 버튼 비가시화
- 옷 목록 영역 전체를 덮는 안내 오버레이 ("TOUCH TO ADD CLOTHES" 톤의 비주얼 안내, [+]버튼 모양을 가운데에 크게 배치하고 상호작용시 해당 버튼 눌리는 효과 재생)
